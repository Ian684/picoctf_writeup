# picoCTF writeup index

The repository is grouped by challenge category. Each directory contains
writeups and, where applicable, solve scripts.

| Category | Approx. entries | Focus |
|---|---:|---|
| [`crypto`](crypto/) | 44 | Ciphers, RSA, encoding, and number theory |
| [`forensics`](forensics/) | 61 | Disk, packet, metadata, and file analysis |
| [`general_skill`](general_skill/) | 31 | Shell, scripting, permissions, and fundamentals |
| [`pwn`](pwn/) | 40 | Memory safety, format strings, and binary exploitation |
| [`reverse`](reverse/) | 78 | Assembly, debugging, patching, and decompilation |
| [`web`](web/) | 56 | Web requests, authentication, injection, and client logic |
| [`blockchain`](blockchain/) | 4 | Smart-contract and blockchain-style challenges |

## Suggested writeup format

When adding a new note, capture the challenge name, observations, tools,
commands or code, the root cause, and the final verification. Keep secrets
and personal data out of public notes, and redact live endpoints or tokens.

## Validation

Solve scripts may depend on challenge files, remote instances, or packages
that are not stored here. Run them only against the original authorized
picoCTF environment or a local reproduction.
